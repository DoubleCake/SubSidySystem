# 项目长期记忆 - SubSidySystem

## 项目概况
- **技术栈**：FastAPI + SQLite 后端，React 18 + TypeScript + Tailwind CSS 前端
- **主要功能**：补贴系统，包含数据预检查、历史错误库管理等
- **运行方式**：`start.bat` 同时启动前后端

## 数据库数据清理记录（2026-03-24）

### Village Group 重复数据修复
**问题**: village_group 表中存在重复的 "xx村xx组" 数据，每个村组有两个ID
**解决**: 
1. 保留引用最多的ID（较小的ID）
2. 迁移家庭户数据到保留的ID
3. 删除无引用的重复记录

**结果**:
- 迁移家庭户: 110 个
- 删除村组记录: 40 条
- 剩余村组总数: 107 个
- 重复村组数: 0 个

**预防措施**:
- 在 `VillageGroup` 模型中添加了唯一约束：`UniqueConstraint('full_name', name='uq_village_group_full_name')`
- 在数据库中创建了唯一索引 `uq_village_group_full_name`
- 确保未来不会出现重复数据

## 用户界面优化记录（2026-03-24）

### 年份选择持久化
**问题**: 用户选择年份后，刷新页面或从子页面返回时，年份选择会丢失
**解决**:
1. 在主项目页面（SubsidyProjectsPage.tsx）使用URL参数保存年份选择
2. 添加 `useLocation` 和 `useNavigate` hooks
3. 修改年份选择器的 `onChange` 处理函数，同时更新状态和URL参数

**实现**:
- 年份选择通过URL参数 `?year=2024` 保存
- 刷新页面或从子页面返回时，自动从URL参数恢复年份选择
- 与React Router深度集成，用户体验流畅

### 人员导入界面数据筛选功能增强
**问题**: 人员导入界面缺乏详细的数据筛选功能
**解决**: 在记录页面（RecordsPage）添加完整的数据筛选面板

**筛选功能**:
1. **村庄筛选**: 下拉选择框，动态加载当前项目的所有村庄
2. **发放状态筛选**: 下拉选择（待发放、发放中、已完成）
3. **金额范围筛选**: 最小金额和最大金额输入框
4. **日期范围筛选**: 开始日期和结束日期选择器
5. **通用搜索**: 姓名/身份证搜索框
6. **清除筛选**: 一键清除所有筛选条件

**技术实现**:
- 添加筛选状态管理（village, payStatus, minAmount, maxAmount, dateFrom, dateTo）
- 修改API调用，支持筛选参数
- 添加村庄列表API端点支持
- 筛选条件变化时自动重置页码

### 批量选择删除功能完善
**问题**: 批量选择删除功能不完整，缺乏用户友好的交互
**解决**: 完善批量选择删除功能，提供完整的用户界面

**功能改进**:
1. **表格全选/取消全选**: 表头复选框支持全选当前页所有记录
2. **单个记录选择**: 每行添加复选框，支持多选
3. **批量删除按钮**: 当有选中记录时，显示批量删除按钮
4. **确认对话框**: 删除前显示确认对话框，防止误操作
5. **视觉反馈**: 选中记录有视觉反馈，显示选中数量

**技术实现**:
- 添加 `selectedIds` 状态管理选中记录ID
- 添加 `toggleSelectAll`、`toggleSelect`、`batchDelete` 函数
- 修改表格结构，添加复选框列
- 添加批量删除API端点支持
- 优化用户交互体验
