## Excel模板映射功能实现 - 2026-03-24

### 需求分析：
用户希望在项目中进行人员导入时，如果拖入的文件不是模板文件（不符合预设的列名），系统能够：
1. 自动检测文件是否为模板文件
2. 如果不是模板文件，允许用户进行字段映射选择
3. 可以将映射关系保存为模板，以便下次使用

### 实现方案：

1. **创建新的Excel导入组件** (`ExcelImportWithMapping.tsx`)：
   - 支持检测文件是否为模板文件
   - 如果不是模板文件，进入列名检测和映射流程
   - 提供字段映射配置界面
   - 支持保存映射关系为模板

2. **修改SubsidyProjectsPage组件**：
   - 替换原有的ExcelImport组件为ExcelImportWithMapping
   - 添加系统字段定义（SUBSIDY_SYSTEM_FIELDS）
   - 添加列名检测API函数（detectExcelColumns）
   - 添加模板保存API函数（saveColumnMappingTemplate）

3. **功能流程**：
   - 用户上传Excel文件
   - 系统检查文件列名是否匹配模板格式
   - 如果是模板文件：直接进入预览导入
   - 如果不是模板文件：进入智能检测流程，自动建议映射关系，用户可手动调整
   - 用户可以将映射关系保存为新模板
   - 完成数据导入

### 技术细节：

1. **模板检测逻辑**：
   ```javascript
   const checkIfTemplateFile = (fileColumns: string[]): boolean => {
     // 检查文件列名是否完全匹配模板列名
     // 或包含所有必填列
   }
   ```

2. **字段映射配置**：
   - 提供下拉选择框，将Excel列映射到系统字段
   - 显示数据示例，帮助用户识别列含义
   - 标记必填字段，确保数据完整性

3. **模板保存**：
   - 收集映射关系
   - 调用后端API保存模板
   - 支持模板名称、适用年度、适用年度、适用村组等元数据
