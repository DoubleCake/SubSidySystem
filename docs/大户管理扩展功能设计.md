# 大户管理扩展功能设计

## 一、地块归属村组管理

### 功能说明
代耕代种的土地可能与大户所属村不同，需要单独记录地块的归属村组信息。

### 数据字段
- `parcel_village_id` - 地块所属村（可与大户所属村不同）
- `parcel_group_no` - 地块所属组

### 应用场景
1. 跨村代耕：大户从邻村农户流入土地
2. 补贴归属：明确土地所在村组，便于补贴统计和管理
3. 责任划分：清晰界定土地归属，避免纠纷

---

## 二、高标/示范片区标识

### 功能说明
标识地块是否属于高标准农田、示范片区等特殊区域。

### 数据字段
- `is_high_standard` - 是否高标准农田
- `is_demonstration` - 是否示范片区
- `zone_name` - 片区名称
- `zone_type` - 片区类型

### 应用场景
1. 政策补贴：特殊片区可能有额外补贴政策
2. 项目管理：便于农业项目实施和跟踪
3. 统计分析：按片区统计种植情况和产量

---

## 三、地块明细表（LargeFarmerParcel）

### 功能说明
精细化管理大户经营的每个地块信息。

### 核心字段

#### 1. 地块四至
- `boundary_east` - 东至
- `boundary_west` - 西至
- `boundary_south` - 南至
- `boundary_north` - 北至

#### 2. 地力等级
- `soil_grade` - 地力等级（优等/良/中/差）
- `soil_type` - 土壤类型
- `irrigation_level` - 灌溉条件

#### 3. 种植信息
- `current_crop` - 当前作物
- `planting_season` - 种植季节
- `planting_year` - 种植年度

---

## 四、地图可视化功能

### 功能说明
通过地图直观展示大户地块分布。

### 数据字段
- `map_coordinates` - 地图坐标点（JSON数组）
- `map_geojson` - GeoJSON格式的地块边界
- `map_center_lng` - 地图中心经度
- `map_center_lat` - 地图中心纬度
- `map_zoom` - 地图缩放级别

### 实现方案
1. **前端地图库**：使用 Leaflet 或高德地图 JS API
2. **地块绘制**：支持在地图上手动绘制地块边界
3. **坐标导入**：支持从 GPS 设备或其他系统导入坐标
4. **可视化展示**：
   - 不同颜色标识不同片区类型
   - 点击地块显示详情
   - 支持缩放、平移

---

## 五、合同到期提醒

### 功能说明
自动提醒即将到期的代耕代种合同。

### 数据字段
- `end_date` - 流转结束日期
- `reminder_sent` - 是否已发送到期提醒
- `reminder_days` - 提前提醒天数
- `payment_status` - 支付状态（未支付/部分支付/已支付）

### 提醒机制
1. **定时任务**：每天检查即将到期的合同
2. **提醒方式**：
   - 系统内消息通知
   - 首页待办事项
   - 可选短信提醒（需要集成短信服务）
3. **提醒时机**：
   - 到期前 30 天
   - 到期前 7 天
   - 到期当天
   - 逾期后

## 六、大户评级体系

### 功能说明
对大户进行评级，便于差异化管理和服务。

### 数据字段
- `farmer_grade` - 大户等级（省级/市级/县级/普通）
- `credit_score` - 信用评分（0-100）

### 评级维度
1. **经营规模**：总经营面积
2. **合同履约**：按时支付租金情况
3. **种植规范**：是否按照农业规范种植
4. **政策执行**：是否积极执行农业政策
5. **信用记录**：有无违规行为

### 应用场景
1. **政策倾斜**：评级高的大户优先享受政策支持
2. **金融服务**：信用评分作为贷款参考
3. **项目优先**：评级高的大户优先承担农业项目

## 八、页面设计建议

### 大户详情页
1. **基本信息**：大户基本情况、评级、信用分
2. **地块列表**：以卡片或表格形式展示所有地块
3. **地图视图**：切换到地图模式查看地块分布
4. **代耕代种记录**：关联的代耕代种合同
5. **统计图表**：面积统计、作物分布等

### 地块管理页
1. **地块列表**：所有地块的列表视图
2. **筛选功能**：按村、片区类型、地力等级筛选
3. **批量操作**：批量修改片区标识、地力等级等
4. **地图模式**：在地图上查看和编辑地块

### 到期提醒页
1. **即将到期**：30天内到期的合同
2. **已到期**：已到期未续签的合同
3. **逾期未付**：租金逾期未支付的合同
4. **批量处理**：批量发送提醒、批量续签

## 九、API 扩展建议

### 新增接口
1. `GET /api/large-farmers/{id}/parcels` - 获取大户地块列表
2. `POST /api/large-farmers/{id}/parcels` - 添加地块
3. `PUT /api/large-farmers/parcels/{id}` - 更新地块
4. `DELETE /api/large-farmers/parcels/{id}` - 删除地块
5. `GET /api/large-farmers/contract-reminders` - 获取合同到期提醒
6. `POST /api/large-farmers/contract-reminders/send` - 发送提醒
7. `GET /api/large-farmers/summary/by-zone` - 按片区统计
8. `GET /api/large-farmers/summary/by-grade` - 按评级统计

### 扩展接口
1. `GET /api/large-farmers/{id}` - 增加地块统计、评级信息
2. `POST /api/large-farmers/{id}/trusts` - 增加地块归属村组、片区标识参数
