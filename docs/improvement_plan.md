# 惠农惠民补贴管理系统 — 完善与扩展规划

## 一、数据导入导出

### 1.1 导入失败明细导出
- **现状**：导入失败行只在前端弹窗展示，无法保存
- **方案**：导入完成后，后端返回失败行的原始数据+错误原因；前端提供「导出失败明细」按钮，在原 Excel 基础上追加"失败原因"列

### 1.2 导入模板一键下载
- **现状**：用户需手动创建 Excel 模板
- **方案**：每个补贴类型提供「下载模板」按钮，预填表头和数据校验规则

### 1.3 补贴发放记录批量导入
- **现状**：`SubsidyPayment` 表已有，导入功能仅支持 Application
- **方案**：复用 `ExcelImportWithMapping` 组件，定义 Payment 专用系统字段

---

## 二、预检与数据校验

### 2.1 预检结果历史记录
- **现状**：预检结果仅当次展示，关闭后丢失
- **方案**：将预检结果存入 `precheck_log` 表，支持按时间回溯

### 2.2 预检规则自定义配置 UI
- **现状**：`check_config` 已支持 JSON 配置，但前端仅在 SubsidyForms 中有简单开关
- **方案**：独立的预检规则配置页面，可视化启用/禁用各项检查

### 2.3 跨项目面积联动检查
- **现状**：预检只检查当前补贴类型，不跨项目对比
- **方案**：检查同一农户在大春+小春+耕地保护项目间的面积总和是否超过承包上限

---

## 三、面积计算与流转管理

### 3.1 流转到期自动提醒
- **现状**：`land_trust` 有 `end_date` 字段，但无到期提醒
- **方案**：Dashboard 增加「即将到期流转」卡片，到期前 30 天高亮

### 3.2 流转历史版本对比
- **现状**：流转记录覆盖更新，无历史版本
- **方案**：每次编辑生成快照存入 `land_trust_history` 表

### 3.3 面积使用趋势图
- **现状**：HouseholdDetail 只有当前面积概览
- **方案**：增加历年面积使用趋势折线图，展示承包/已用/剩余的变化

---

## 四、报表与统计分析

### 4.1 补贴发放汇总报表
- **方案**：按年度/村/补贴类型维度汇总，支持导出 Excel
- **字段**：村名、组号、户数、人数、申报面积、发放金额、资金来源

### 4.2 超领预警报表
- **方案**：列出所有 `is_overdrawn=true` 的家庭户，含超领面积、涉及补贴类型

### 4.3 资金来源分析
- **现状**：`SubsidyType.fund_source` 已定义（中央/省级/县级），但无汇总
- **方案**：Dashboard 增加资金来源饼图

---

## 五、用户操作体验

### 5.1 批量操作
- **现状**：删除/发放需逐条操作
- **方案**：列表增加多选 checkbox，支持批量删除、批量标记发放

### 5.2 操作日志
- **现状**：`AuditLog` 表已定义但几乎未使用
- **方案**：关键操作（导入、删除、修改补贴金额）自动写入审计日志

### 5.3 快捷键支持
- **方案**：录入表单支持 Tab 切换、Enter 提交、Esc 关闭

### 5.4 移动端适配
- **现状**：当前为桌面端设计
- **方案**：响应式布局，表格在小屏改为卡片视图

---

## 六、数据完整性与安全

### 6.1 软删除
- **现状**：删除操作直接物理删除
- **方案**：增加 `is_deleted` 字段，关键表支持软删除+恢复

### 6.2 数据备份增强
- **现状**：`BackupPage` 已支持手动备份
- **方案**：增加定时自动备份、备份文件下载、异地备份提示

### 6.3 身份证脱敏一致性
- **现状**：`mask_id_card` 已实现，但部分导出未脱敏
- **方案**：所有导出接口统一脱敏处理

---

## 七、系统性能

### 7.1 缓存预热
- **现状**：面积缓存在导入后异步重算
- **方案**：系统启动时预加载常用村/户的面积缓存

### 7.2 列表虚拟滚动
- **现状**：大户量时表格渲染卡顿
- **方案**：引入虚拟滚动（如 react-window），万行级流畅滚动

### 7.3 API 响应压缩
- **方案**：FastAPI 中间件启用 gzip 压缩

---

## 八、外部集成

### 8.1 银行代发文件导出
- **方案**：按银行要求格式导出 Excel/CSV，包含卡号、姓名、金额

### 8.2 公示名单生成
- **方案**：一键生成村组公示名单 PDF，包含户主姓名、补贴项目、面积、金额

---

## 优先级建议

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P0 | 导入失败明细导出 | 直接影响日常工作流 |
| P0 | 操作日志 | 审计合规刚需 |
| P1 | 超领预警报表 | 核心业务价值 |
| P1 | 补贴发放汇总报表 | 日常统计刚需 |
| P1 | 流转到期提醒 | 防止数据过期 |
| P2 | 批量操作 | 提升操作效率 |
| P2 | 公示名单生成 | 村务公开需求 |
| P3 | 移动端适配 | 现场办公需求 |
| P3 | 虚拟滚动 | 大户量场景优化 |
